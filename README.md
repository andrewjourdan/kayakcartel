# Kayak Cartel

**Every Shoreline. Every State. One Crew.**

**Website:** [kayakcartel.com](https://kayakcartel.com)
**Join the Crew:** join@kayakcartel.com
**Franchise information requests:** session@kayakcartel.com
**Sponsorship:** sponsorship@kayakcartel.com

Kayak Cartel is a concept for a national network of kayak, canoe, paddle board and rafting rental outfitters and dealers, connected by shared referrals, a single booking system, linked social channels and national sponsors.

## Files

| File | Purpose |
|---|---|
| `index.html` | The complete single-page website. All styles, scripts and artwork are contained in this one file. |
| `README.md` | This file. |
| `CNAME` | Created by GitHub Pages when the custom domain is set. Do not delete. |

## Hosting

The site is served by GitHub Pages from the `main` branch, root folder, with the custom domain `kayakcartel.com`. No build step is required.

## Maintenance and checks

Canonical URL: https://kayakcartel.com/. Preserve CNAME. Run `python3 scripts/check_site.py` before submitting a pull request; GitHub Actions runs the same check for metadata, local links, sitemap, robots and preview disclosures.

The booking search is a preview. The dealer form prepares an email information request; nothing is sent until the visitor sends the email. Neither action creates a reservation, application or territory agreement.

Review mobile and desktop layouts and email links before publishing. Main requires pull requests and Site checks, and force pushes and deletion should remain blocked. Domain transfer lock, auto-renewal, DNSSEC, GitHub Pages domain verification and delivery to the three published mailboxes require separate verification.
